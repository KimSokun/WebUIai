# 📁 K-Jocker GGUF Models Directory

Place your `.gguf` quantized models here for local llama.cpp inference.

### Example Models:
- `k-jocker-1.5flash-q5_k_m.gguf` (Recommended for balanced speed & reasoning)
- `k-jocker-1.5flash-q4_k_m.gguf` (Lightweight, low RAM usage)
- `k-jocker-1.5flash-q8_0.gguf` (Maximum precision)

### Auto-Detection:
Any file ending with `.gguf` placed in this directory will automatically be detected by the K-Jocker Owner AI backend and made available in the Web UI model dropdown selector.
